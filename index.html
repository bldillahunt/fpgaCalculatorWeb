How It Works

This calculator emulates how an FPGA performs hardware math and bitwise logic. All operands are converted to binary before executing operations, and results are converted from binary into your selected output format. It can also be used as a direct data type converter.

Supported Data Types

  • Real: Standard signed decimal numbers.
  • Hexadecimal: Enter directly without a 0x prefix.
  • 2's Complement Binary: Enter directly without a 0b prefix; supports a binary point (e.g., 101.11) for Q-format fixed-point values. Short binary inputs are automatically sign-extended to match the required nibble/bit width for hexadecimal conversions and outputs (for example, 111 extends to 1111, while 011 extends to 0011).
  • IEEE-754 Single (FP32) & Double (FP64): Standard floating-point representations.

Operations & Syntax

  • Math Operations: Addition (+), subtraction (-), multiplication (*), division (/), and modulo (%).
  • Bitwise & Logic Operations: AND (&), OR (|), XOR (^), NOT (~), and 2's complement (!).
  • Formatting Rules: Enter two-operand expressions as operand1 operator operand2 and single-operand expressions as operator operand with no spaces.

Bit Width Configuration

The Integer Bits and Fraction Bits settings control the fixed-point precision used for hexadecimal entries and division results.
